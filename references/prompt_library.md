## Phase 2：資料清洗 Prompts

### 🔹 Prompt 2-1：通用髒資料清洗指令

```markdown
你是一位具備 15 年經驗的資深數據工程師。我已上傳一份原始資料檔案。

請仔細檢查資料結構，並呼叫 Python / Pandas 代碼執行器完成嚴格清洗：

### 執行規則：
1. **去除空白**：所有文字欄位的前後空白（Trim Whitespace）。
2. **千分位字串數值化**：包含逗號千分位的數字（如 "14,321,556"）強制轉換為純數值 Float / Int。
3. **百分比轉數值**：去除 % 符號（如 "28.4%" → 28.4）。
4. **缺失值標準化**："-"、"NaN"、"null"、"N/A"、空白 → 統一轉為 None/空值。
5. **日期紀年標準化**：民國格式（如 11509 或 115/09）→ ISO 格式 2026-09。
6. **完全空白列移除**：自動刪除。
7. **輸出清洗摘要**：總行數、修復筆數、數值轉換數量。

請輸出乾淨版的 CSV 供下載，並提供清洗摘要統計表。
```

### 🔹 Prompt 2-2：臺灣上市公司營收清洗（1,088 家版）

```markdown
你是一位資深商業與金融數據工程專家。我已上傳由臺灣證交所（TWSE）彙整的真實市場檔案
`TWSE_上市公司營收_1088家.csv`（共 1,088 家公司）。

請呼叫代碼執行器（Python / Pandas）完成：
1. 去除「公司名稱」、「產業別」等欄位的前後空白。
2. 將包含逗號千分位的營收數字（如 "14,321,556"）強制轉換為純數值。
3. 將「資料年月」欄位民國格式（如 11509 或 115/09）精準換算為 ISO 格式（2026-09）。
4. 標記「上年同月」為 "-" 或缺失的列，轉為空值（不計為 0）。
5. 輸出清洗摘要：總行數、修復筆數、數值轉換數量。
```

## Phase 3：EDA 探索性分析 Prompts

### 🔹 Prompt 3-1：描述性統計（通用版）

```markdown
資料已清洗完成。請對以下欄位執行完整探索性分析（EDA）：

1. 基本描述性統計（每個數值欄位）：
   n、mean、median、std、min、max、Q1（25%）、Q3（75%）

2. 極端值識別：
   找出排行前 3 名與後 3 名，說明其顯著特徵。

3. 分佈形態：
   正偏/負偏/常態分佈？若有離群值，標記並說明可能原因。

請以 Markdown 表格格式輸出，數字保留小數點後 2 位。
```

### 🔹 Prompt 3-2：產業板塊分析（臺灣上市公司版）

```markdown
請根據清洗後的 1,088 家上市公司營收資料，執行產業板塊 EDA：

1. 各「產業別」當月總營收加總，計算佔全市場百分比，輸出前五大支柱產業。
2. 各產業平均年增率（YoY%）排行，找出成長最快與最慢各 3 個產業。
3. 全市場 YoY 成長率前五大黑馬企業（引用具體公司名稱與數值）。
4. 提供 3 點高價值產業集中度觀察（嚴格引用具體數字，禁止空話）。
```

### 🔹 Prompt 3-3：時序趨勢分析

```markdown
請執行時序趨勢分析：

1. 折線圖：目標指標的年度/月度趨勢。
2. 7 期移動平均（MA7）：過濾短期雜訊。
3. 標記趨勢拐點（上升轉下降 or 下降轉上升）。
4. 與前一年同期比較，計算年增率（YoY%）。
5. 若有季節性，標記旺季與淡季區間。
```

## Phase 4：防幻覺算術驗算 Prompts

### 🔹 Prompt 4-1：加總勾稽（必用）

```markdown
【防幻覺核對任務 · Cross-Verification Required】

在提供任何數值統計結論前，請先執行算術交叉勾稽：

1. 將所有個別數值加總 → S1（由下而上）。
2. 從資料總計欄讀取 → S2（原始總額）。
3. 驗證 S1 - S2 = 0。

請以 Markdown 表格輸出驗算憑據：
| 驗算項目 | 計算式 | 結果 | 狀態 |
|:---|:---|:---|:---|
| 各項加總 S1 | A+B+... | = ___ | ✅ PASS 或 ⚠️ FLAG |
| 原始總計 S2 | 直接讀取 | = ___ | ✅ PASS 或 ⚠️ FLAG |
| 差額 S1-S2 | | = ___ | ✅ PASS 或 ⚠️ FLAG |

請調用 Python Code Interpreter 計算，不得靠語言預測！
```

### 🔹 Prompt 4-2：比率計算透明化

```markdown
凡涉及「佔比（%）」或「成長率」，必須展示：

【分子】 ÷ 【分母】 × 100 = 【計算結果%】

例如：
- 半導體業佔比：NT$450億 ÷ NT$1,800億 × 100 = 25.0%
- YoY 成長率：(2026年營收 - 2025年營收) ÷ 2025年營收 × 100 = ____%

請確保每個比率旁邊都有此透明化算式，學員可自行驗算。
```

## 模組 B：AI 客服「數位乩童」Prompts

### 🔹 Prompt B-1：Google Apps Script BFF 代理腳本生成

```markdown
請幫我建立一個 Google Apps Script (GAS) 後端中繼代理，充當「數位乩童」AI 客服的 BFF：

要求：
1. `doPost(e)`：接收前端傳來的 JSON 封包（包含 message, context, imageBase64, sessionId, history）。
2. 資安防護：使用 `PropertiesService.getScriptProperties().getProperty("OPENROUTER_API_KEY")` 讀取金鑰，絕不在程式碼內寫死 Key。
3. 呼叫 OpenRouter：呼叫 `https://openrouter.ai/api/v1/chat/completions`，使用 `anthropic/claude-3.5-haiku` 模型。
4. 多模態支援：若前端傳入 `imageBase64`，自動組裝為 OpenRouter Vision image_url 格式。
5. 試算表日誌：若設定了 `LOG_SHEET_ID`，透過 `SpreadsheetApp.appendRow()` 自動寫入時間戳記、提問、回答摘要與截圖標記。
6. 回傳格式：使用 `ContentService.createTextOutput(JSON.stringify(res)).setMimeType(ContentService.MimeType.JSON)` 回傳，避開 CORS 問題。
7. `doGet(e)`：提供健康檢查端點。
```

### 🔹 Prompt B-2：前端網頁浮動按鈕與框選截圖功能注入

```markdown
請在我的網頁右下角注入一個「數位乩童」AI 客服浮動按鈕：

要求：
1. 外觀：極簡圓角紫藍漸層浮動按鈕（FAB），標題為「數位乩童」，副標題為「請解簽」，帶有綠色在線指示燈與圓形頭像。
2. 展開視窗：點擊展開現代對話視窗，支援自適應手機與桌面版。
3. 框選截圖功能：
   - 提供「📷 畫面框選截圖」按鈕。
   - 點擊後畫面出現半透明暗色遮罩，游標變成十字準心，允許滑鼠拖曳拉出矩形選區。
   - 選取放開後，使用 `html2canvas` 針對該座標範圍截圖，轉為 Base64 並自動預覽於輸入框上方。
4. 請求發送：
   - 使用 `fetch(gasUrl, { method: 'POST', redirect: 'follow' })` 送往 Google Apps Script Web App。
   - 正確處理 GAS 產生的 HTTP 302 重定向。
5. 歷史狀態：維持本地多輪對話歷史，並在畫面上顯示 AI 靈光思考動畫。
```

```markdown

   - 頂部導覽列：標題、資料來源與 Tableau Prep 智慧欄位分類微調按鈕。

   - 中央畫布：使用 Apache ECharts 渲染 60FPS 流暢互動圖表。
```

## 模組 D：60 秒動態數據短片 Prompts

### 🔹 Prompt D-1：數據短片黃金五段式分鏡腳本生成

```markdown
你是一位獲獎級商業數據視覺化影片導演。請為我的一組核心商業指標設計一份「60 秒動態短片分鏡腳本」：

結構要求（黃金五段式）：
1. 00s-05s【Hook 視覺衝突】：提出震撼性問題或反常識數據對比（如「全台 70% 偏鄉空屋，都會房價卻連漲 10 年？」）。
2. 05s-20s【第一動態：離散體量到趨勢拐點】：柱狀圖升起（Squash & Stretch 動量），柱頭鎖定為折線錨點，展現 5 年時序變化。
3. 20s-35s【第二動態：相關矩陣與離群點爆發】：折線爆發為散點粒子雲，繪出迴歸趨勢線，標記 3 個異常離群個案。
4. 35s-50s【第三動態：結構佔比與多維平衡】：粒子收斂為甜甜圈佔比圖，切換至六維雷達圖評估體質。
5. 50s-60s【CTA 決策收尾】：總結一句話核心洞察，給出具體行動建議。

音效要求：
- 標註 Earshot 物理打點音效（UI Click、Thock、Sub Hit）。
- 標註語音旁白出現時的 Auto-Ducking 避讓時間點。
```
