## 三段論商業洞察報告

### 📊 現況事實（What is happening）

根據教育部 112 學年度資料，全台 140 所大專院校共有**全時制專任教師 47,894 人**，平均每所院校 342 人，但標準差高達 421，顯示師資規模呈現嚴重兩極化。公立大學佔全台專任師資的 **65.2%**（31,205 人），而私立院校雖佔校數約 70%，卻僅有 34.8% 的師資份額，**師生比最不利的私立院校達到 1:38.5**，遠超教育部建議的 1:25。

### 🔍 深度原因（Why it matters）

少子化導致私立院校招生壓力持續上升，財務緊縮使其難以新增專任教員，轉而以兼任師資彌補教學需求，形成惡性循環。同時，公立大學受惠於政府年度常規預算與科技部計畫，師資擴充空間遠大於私立院校，長期加劇了兩者的師資結構落差。

### 🚀 行動建議（What should we do）

1. **教育部政策面**：針對師生比超過 1:30 的私立院校，建立「師資補強輔導計畫」，提供 3 年期師資共聘補助，協助院校招募具博士學位的專任助理教授，目標在 2026–2029 年將全國私立院校平均師生比從 1:31 改善至 1:27。

2. **院校自強面**：私立院校可主動建立「師資共聘聯盟」，同性質院校（如科技大學聯盟）共同招募跨校任教的全時制師資，分攤薪資成本，同時滿足課程覆蓋需求，初期目標可設定 5 所院校聯合招募 20 名共聘教師。
